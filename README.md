# 🚀 Squard Goalz API Server (초보 팀원 완벽 가이드)

환영합니다! 🎉 이 문서는 코딩을 갓 시작한 팀원들도 절대 길을 잃지 않도록 파이썬 설치부터 서버 실행까지 A to Z를 안내하는 가이드입니다. 
급하게 마음먹지 말고, 1번부터 차근차근 따라와 주세요!

## 🛠 0. 우리가 사용할 도구들
* **언어:** Python 3.12+ 
* **프레임워크:** FastAPI (아주 빠르고 쉬운 웹 서버 도구)
* **데이터베이스:** PostgreSQL (Neon DB)
* **에디터:** Visual Studio Code (VS Code)

---

## 👣 1단계: 필수 프로그램 설치하기 (내 컴퓨터 세팅)

코딩을 시작하기 위해 필요한 기본 프로그램 3가지를 설치합니다.

### 1. 파이썬(Python) 설치
1. [파이썬 공식 홈페이지](https://www.python.org/downloads/)에 접속해서 다운로드 버튼을 누릅니다.
2. 다운받은 설치 파일을 실행합니다.
3. 🚨 **(가장 중요!)** 설치 창 맨 아래에 있는 **[v] Add Python.exe to PATH** 체크박스를 **무조건 체크**한 뒤 `Install Now`를 눌러 설치합니다. (이걸 안 하면 명령어가 안 먹힙니다!)

### 2. VS Code (코드 편집기) 설치
1. [VS Code 공식 홈페이지](https://code.visualstudio.com/)에서 다운로드 후 설치합니다. (모두 '다음' 누르시면 됩니다.)

### 3. Git 설치
1. [Git 다운로드 페이지](https://git-scm.com/downloads)에서 윈도우용(또는 맥용)을 다운받아 설치합니다. (마찬가지로 쭉 'Next' 누르시면 됩니다.)

## 📥 2단계: 프로젝트 코드 가져오기

1. 컴퓨터 바탕화면에 새 폴더를 하나 만듭니다. (예: `my-coding`)
2. 해당 폴더를 VS Code로 엽니다. (VS Code 상단 메뉴 `파일` > `폴더 열기`)
3. VS Code 위쪽 메뉴에서 `터미널` > `새 터미널`을 클릭해 화면 아래에 까만 창을 켭니다.
4. 터미널 창에 아래 명령어를 복사/붙여넣기 하고 Enter를 칩니다. (우리 팀의 코드를 다운받는 과정입니다.)
```bash
git clone (여기에_우리팀_깃허브_주소를_넣어주세요)
```
5. 다운로드가 끝나면 `squard-goalz` 폴더가 생깁니다. VS Code의 `파일` > `폴더 열기`를 눌러 방금 생긴 **`squard-goalz` 폴더 안으로 다시 들어가서 엽니다.**

## 🛡️ 3단계: 가상 환경과 패키지 세팅

우리 프로젝트만의 독립적인 놀이터(가상 환경)를 만들고 필요한 부품을 조립할 차례입니다.
VS Code에서 `터미널` > `새 터미널`을 엽니다.

### 1. 가상 환경 만들기 및 켜기
```bash
# 놀이터(가상 환경) 만들기
python -m venv venv

# 놀이터로 들어가기 (Windows 용)
.\venv\Scripts\activate

# 놀이터로 들어가기 (Mac 용)
source venv/bin/activate
```
*(성공하면 터미널 입력줄 맨 앞에 초록색으로 **`(venv)`** 라는 글자가 생깁니다. 앞으로 작업할 땐 항상 이게 켜져 있어야 합니다!)*

### 2. 필수 부품(패키지) 설치하기
`(venv)`가 켜진 상태에서 아래 명령어를 복사해 붙여넣고 Enter를 칩니다.
```bash
pip install "fastapi[standard]" psycopg2-binary python-dotenv cryptography sqlalchemy alembic
```

## 🔑 4단계: 비밀번호 상자(.env) 만들기

데이터베이스 접속 정보나 암호화 키는 해커가 보면 안 되기 때문에 깃허브에 올리지 않습니다. 각자의 컴퓨터에 직접 만들어야 합니다.

1. VS Code 좌측 탐색기 빈 공간을 우클릭하고 **`새 파일`**을 누릅니다.
2. 파일 이름을 **`.env`** 로 짓고 엽니다. (앞에 마침표 꼭 찍으세요!)
3. 아래 내용을 복사해서 붙여넣습니다. (**실제 값은 팀장님께 카톡이나 슬랙으로 물어보세요!**)

```env
DB_HOST=팀장님이_알려준_주소
DB_NAME=sq_goalz
DB_USER=DB_아이디
DB_PASSWORD=DB_비밀번호
AES_SECRET_KEY=팀장님이_알려준_32자리_비밀키
```
4. `Ctrl + S` 를 눌러 저장합니다.

## 📡 5단계: DB 연결 확인 및 서버 켜기

이제 모든 준비가 끝났습니다! 코드를 실행해 볼까요?

### 1. 데이터베이스 최신화 (테이블 생성)
우리가 파이썬으로 짠 구조를 실제 DB에 반영해 줍니다. 터미널에 아래 명령어를 칩니다.
```bash
alembic upgrade head
```

### 2. 드디어 서버 실행!
터미널에 아래 명령어를 치면 서버가 켜집니다.
```bash
fastapi dev main.py
```

### 3. 눈으로 확인하기 👀
인터넷 창(크롬 등)을 열고 주소창에 아래 주소를 입력하세요.
👉 `http://127.0.0.1:8000/docs`

우리가 만든 API 서버의 예쁜 테스트 화면(Swagger UI)이 나옵니다. 성공입니다!! 🎉
